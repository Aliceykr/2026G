# G题无屏联调与标定说明

最后更新：`2026-07-29 19:21:30 +08:00`

## 1. 当前目的

淘晶驰6英寸串口屏到货前，先用USART1完成G题测量核心联调。当前无屏
闭环覆盖：

- `1.25 MSPS / 4096点`频谱分析；
- 基频和最多3个基波/谐波分量识别；
- 按频率插值的码值到毫伏换算；
- 校准后输入`Upp`和真`Urms`计算；
- `5 MSPS`波形帧的1周期/3周期相位对齐；
- 固定256点波形绘图数据；
- 参数与波形处理耗时及`2s`判定。

当前最终采集链仍为：

```text
AD9238 CH1
  -> FPGA CIC与低通
  -> 1.25 MSPS分析帧 / 5 MSPS波形帧
  -> SPI1
  -> STM32频谱、毫伏参数和波形数据
  -> USART1调试
```

ADS1256不进入G题最终采集链。

## 2. 串口输出

USART1当前使用`115200, 8N1`。

双向联调接线：

```text
STM32 PA9  (TX) -> USB-TTL RX
STM32 PA10 (RX) <- USB-TTL TX
STM32 GND       -> USB-TTL GND
```

USB-TTL必须使用`3.3V TTL`电平。只接PA9和GND时可以接收STM32输出，但
电脑发送的`1`或`3`无法进入STM32。

### 2.1 原始频谱结果

```text
G_FLOW,seq=0,f0=100000Hz,n=2,rms=...,vpp=...,t_ms=...,under2s=1,...
```

- `rms`、`vpp`和各`hN`幅值仍为FPGA码值；
- `t_ms`是启动分析帧到参数结果可用的时间；
- `under2s=1`表示该次参数处理不超过2秒。

空输入或最强拟合分量低于当前`16 codes`门限时：

```text
G_FLOW,no_signal,seq=0,t_ms=...,under2s=1,threshold=16
```

此时不会再输出随机`f0/hN`，也不会启动无意义的周期波形提取。实测
50mVpp在10～500kHz范围内最小`h1`仍为653 codes，约为当前16-code
门限的40.8倍，因此不会把题目规定的最小有效输入误判为无信号。

### 2.2 毫伏结果

实机标定前：

```text
G_MEAS,seq=0,cal=0,reason=no_mv_table
```

这表示程序拒绝输出未经标定的伪毫伏值。

标定表生效后：

```text
G_MEAS,seq=0,cal=1,f0=100000Hz,upp=200mV,urms=71mV,n=2,...
```

各`hN`后的幅值是相应正弦分量的峰值，单位为毫伏。

### 2.3 波形结果

每4帧输出一次完整波形数据，降低115200波特率下的串口占用。

```text
G_WAVE,seq=0,cycles=1,n=256,fs=5000000,start=...,span=...,t_ms=...,under2s=1
G_WAVE_DATA,seq=0,off=0,...
```

- `cycles`为1或3；
- `n=256`为绘图点数量；
- `points`已经去除直流均值并按基波相位对齐；
- `t_ms`是分析帧启动到波形数据可用的总时间。

后续串口屏适配层直接读取`GSignalFlow_GetLatestMeasurement()`和
`GSignalFlow_GetLatestWaveform()`，不再重新计算FFT或波形周期。

## 3. 1周期/3周期切换

无屏联调时，可在串口工具中发送单个ASCII字符。固件接收队列也允许
串口工具在字符后自动附加回车换行：

| 字符 | 作用 |
|---|---|
| `1` | 后续波形数据切换为1个完整周期 |
| `3` | 后续波形数据切换为3个完整周期 |

固件确认后返回：

```text
G_CMD,wave_cycles=3,ok=1
```

淘晶驰屏的三个按钮弹起事件分别配置为：

```text
printh 55
printh 01 00 00
printh ff ff ff
```

和：

```text
printh 55
printh 02 00 00
printh ff ff ff
```

和：

```text
printh 55
printh 03 00 00
printh ff ff ff
```

`b3`弹起事件：

```text
printh 55
printh 04 00 00
printh ff ff ff
```

固件将按钮`0x01`映射为时域测量，将按钮`0x02`映射为只切换`s0`的
1/3周期，将按钮`0x03`映射为频域测量。ASCII `1`/`3`命令仍可直接
选择`s0`周期。

当前淘晶驰页面控件映射：

| 控件 | 显示内容 |
|---|---|
| `b0` | 时域测量；只更新`t0/t1/t2/t6/s0` |
| `b1` | 切换`s0`的1周期/3周期，与`s1`无关 |
| `b2` | 频域测量；按钮文字为“频域测量”，更新`t3/t4/t5/s1`和`t6`状态 |
| `b3` | 量程切换；默认开启，仅开关Vpp内部重建使用的0.5mV幅值量化；H分量和Vrms始终显示原生小数值 |
| `s0` | 当前1周期或3周期时域波形；5 MSPS原始帧经四点三次插值生成256点，再按控件实际宽度平滑映射并左右镜像；透明传输校验FE/FD应答 |
| `s1` | 10～500kHz定性频谱；绘制检测到的最多三个实际分量（基波加最多两个谐波，谐波次数不限于H2/H3），整组峰平移到视窗中间且保持原频率间距比例，峰高按幅值比例，频谱区域不显示任何文字；启动及未测量时只清空通道，不发送波形原始数据 |
| `t0` | 基波频率`F`，Hz，整数显示 |
| `t1` | 输入峰峰值`Vpp`，mV，固定两位小数 |
| `t2` | 真有效值`Vrms`，mV，固定两位小数 |
| `t3`～`t5` | 按实际分量顺序显示基波及最多两个已检测谐波，例如检测到H1/H2/H4时依次显示`H1`、`H2`、`H4`；频率为整数、幅值保留两位小数，控件`txt_maxl`至少设为24 |
| `t6` | 时域和频域共用状态：测量中为`BUSY`，完成为`READY`，失败显示错误；使用ASCII避免屏幕字库不兼容 |
| `t7`～`t9` | 不再使用 |

屏幕尚未测量或当前无有效数值时，所有文本均使用`KEY=XXX`格式，例如
`F=XXXHZ`和`H=XXXHZ,XXX.XXmV`。正常测量时，`t3`～`t5`
按检测结果中的实际分量顺序显示，例如`H1=100000HZ,60.00mV`、
`H2=200000HZ,20.00mV`、`H4=400000HZ,10.00mV`。

淘晶驰屏独占UART4：PA0连接屏幕RX，PA1连接屏幕TX，使用
`921600 8N1`。USART1仍连接USB-TTL并输出`G_FLOW/G_MEAS/G_WAVE`调试流，
两路串口互不干扰。UART4的句柄、GPIO复用、时钟、NVIC、IRQ入口和接收
队列全部封装在`App/Src/tjc_usart_hmi.c`中。

业务层使用：

```c
GSignalFlow_SetWaveformCycles(1U);
GSignalFlow_SetWaveformCycles(3U);
```

除1和3以外的参数会被拒绝。该接口只影响`s0`，不会触发或重画`s1`。

## 4. 毫伏标定

标定表位于：

```text
App/Src/GMeasurementCalibration.c
```

当前表已于2026-07-29完成整机实测并写入固件。测试使用High-Z信号源，
每个频点均包含50、100、200、250mVpp四档单频正弦。每个标定点按以下
公式和四档数据强制过原点最小二乘拟合：

```text
mv_per_code =
    信号源该正弦分量的峰值(mV) / STM32输出的amplitude_codes
```

若信号源设置的是单频正弦峰峰值：

```text
正弦分量峰值 = Vpp / 2
```

不要用组合信号总`Upp`除以某一个谐波的`amplitude_codes`。

实测结果：

| 频率 | `mv_per_code` | 最大四档拟合残差 | 平均频率误差 |
|---:|---:|---:|---:|
| 10kHz | 0.035275259 | 0.295mV | -4.80Hz |
| 50kHz | 0.035068414 | 1.060mV | -3.05Hz |
| 100kHz | 0.034883149 | 0.092mV | -4.37Hz |
| 200kHz | 0.035057586 | 0.330mV | +5.24Hz |
| 300kHz | 0.035663438 | 0.240mV | +1.97Hz |
| 400kHz | 0.035773331 | 0.299mV | -3.06Hz |
| 500kHz | 0.036831843 | 0.173mV | +5.39Hz |

固件中的当前表为：

```c
static const GMeasurementCalibrationPoint s_CalibrationPoints[] =
{
    {  10000.0f, 0.035275259f },
    {  50000.0f, 0.035068414f },
    { 100000.0f, 0.034883149f },
    { 200000.0f, 0.035057586f },
    { 300000.0f, 0.035663438f },
    { 400000.0f, 0.035773331f },
    { 500000.0f, 0.036831843f }
};
```

频点之间由程序线性插值，范围外使用最近端点。更换模拟前端、增益、
终端方式或ADC/FPGA缩放后，必须重新采集并生成整张表，不能继续使用
当前系数。

## 5. 无屏阶段验收顺序

1. 下载G题串口目标，确认FPGA ID和连续帧正常。
2. 用单频信号完成10kHz至500kHz幅频标定。
3. 确认串口由`cal=0`变为`cal=1`。
4. 分别验证50mVpp、100mVpp和250mVpp。
5. 验证基波加1个谐波、基波加2个谐波。
6. 验证题目示例`10.5kHz + 31.5kHz + 42kHz`。
7. 加入`200mVpp、1MHz及以上`单频干扰。
8. 每个场景记录最大绝对误差和`under2s`，不要只记录平均误差。

最终判据：

| 指标 | 判据 |
|---|---:|
| `Upp` | 绝对误差不超过5mV |
| 真`Urms` | 绝对误差不超过5mV |
| 基频 | 绝对误差不超过1kHz |
| 每个频谱分量幅值 | 绝对误差不超过5mV |
| 参数与波形结果 | 各自在2秒内可用 |

## 6. 2026-07-29最终无屏实测结果

### 6.1 题目三分量组合

信号源设置：

```text
H1: 10.5kHz，120mVpp
H3: 31.5kHz，60mVpp
H4: 42kHz，40mVpp
```

对应分量峰值为`60/30/20mV`，理论`Upp`约`154.89mV`，理论真
`Urms`约`49.50mV`。实机连续帧稳定得到：

```text
G_MEAS,cal=1,f0=10502Hz,upp=157mV,urms=50mV,n=3,
h1=10502Hz:60mV,h3=31506~31507Hz:30mV,h4=42009Hz:20mV
```

最大频率误差`9Hz`，最大分量幅值显示误差`0mV`，`Upp`误差
`2.11mV`，真`Urms`误差`0.50mV`。参数结果约`151ms`，3周期波形结果
约`291ms`，均通过当前判据。

### 6.2 FFT频谱分析与测量计算

当前`1.25MSPS / 4096点`的原始FFT频率间隔约`305.18Hz`，满足题目
不大于`500Hz`的分辨率要求。最终频率不是直接取整数FFT bin，而是经过
谱峰插值和正弦最小二乘拟合，因此实机频率误差可显著小于一个FFT bin。

已通过的计算链包括：

```text
FFT找峰
  -> 谱峰频率插值
  -> 谐波匹配与非谐波spur诊断
  -> 正弦最小二乘幅值/相位拟合
  -> 频率标定换算为mV
  -> Upp、真Urms和1/3周期波形
```

覆盖证据包括`10~500kHz`单频、独立`150kHz`插值、题目
`H1/H3/H4`组合、`300kHz`非谐波`spur`和无信号门限。当前FFT频谱
分析及测量值计算模块判定为通过，不再需要针对现有实测数据修改系数或
算法。

### 6.3 `1MHz / 200mVpp`抗干扰

最终测试不使用信号源通道合并功能，而是在单通道谐波模式下设置：

```text
H1:  100kHz，120mVpp
H3:  300kHz，60mVpp
H4:  400kHz，40mVpp
H10: 1MHz，200mVpp干扰
```

实机结果：

```text
G_FLOW,seq=4046,f0=99998Hz,n=3,t_ms=151,under2s=1,
h1=99998Hz:1721,h3=299993Hz:838,h4=399991Hz:559,spur=none
G_MEAS,seq=4046,cal=1,f0=99998Hz,upp=154mV,urms=49mV,n=3,
h1=99998Hz:60mV,h3=299993Hz:30mV,h4=399991Hz:20mV
```

加入干扰后，三个有效分量仍为`60/30/20mV`，最大频率误差`9Hz`，
`Upp`和真`Urms`误差均小于`1mV`，参数结果`151ms`。该结果证明
当前数字滤波、FFT识别和毫伏测量链在该测试条件下通过。

`spur=none`表示滤波后的分析帧内没有有效非谐波峰，不表示信号源端
没有施加干扰。最终报告应同时保存信号源设置或装置BNC输入端的示波器
FFT截图。

### 6.4 无效合路数据说明

曾通过信号源通道合并功能加入`1MHz`或`300kHz`信号，低频三分量从
`60/30/20mV`同比下降到约`52/26/17mV`；关闭附加信号后立即恢复。
该现象属于信号生成/合路后的幅值变化，不能据此修改G题标定表。

最终改用单通道高次谐波后，三个有效分量恢复并保持`60/30/20mV`。
因此通道合并数据只作为接线与信号源配置排查记录，不作为装置达标或
不达标证据。

## 7. 串口屏到货后仍需完成

- 确认具体型号、分辨率和串口电平；
- 建立参数页、1/3周期波形页和正频率频谱页；
- 绑定触摸事件；
- 将256点波形映射到实际绘图区；
- 根据最多3个分量生成谱线位置和相对高度；
- 测量从上电或触摸操作到屏幕稳定显示的完整时间；
- 验证屏幕对角线、单路5V供电、BNC输入和整机装配要求。

屏幕端必须复用当前测量结果，不重新实现FFT、标定或`Upp/Urms`计算。
当前无屏串口数据可作为屏幕接入后的固定回归基线。
