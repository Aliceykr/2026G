## 3. 关键接口

- FPGA ID：`0x000004D2`
- SPI1：PA4片选，PA5/PA6/PA7
- USART1：PA9/PA10，`115200 8N1`
- 串口输出：`G_FLOW`、`G_MEAS`、`G_WAVE`、`G_WAVE_DATA`
- 串口输入：ASCII `1`或`3`
- G题分析帧：`1.25MSPS / 4096点`
- 波形帧：`5MSPS / 4096点`
