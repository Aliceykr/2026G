# 2026 年全国大学生电子设计竞赛 G 题

## 周期信号测量分析装置

本仓库是 2026 年全国大学生电子设计竞赛赛区赛（TI 杯）G 题“周期信号测量分析装置”的核心工程。系统采用 `STM32F407ZG + Cyclone IV E FPGA` 架构，对 50 Ω 信号源输出的周期信号进行采集、抗干扰滤波、频谱分析、参数测量和串口屏显示。

仓库只保留可重新构建固件所需的源码、标定数据、IP 和工程配置；构建产物、测试程序、报告及工具缓存均未保留。

## 题目目标

装置需要测量由基波和 1～2 个谐波组成的周期信号，并在不超过 2 秒的时间内完成显示或测量：

| 测试条件 | 输入范围 | 要求 |
|---|---|---|
| 基本要求 | 100～250 mVpp，10～200 kHz | 显示 1 个或 3 个完整周期、`Upp`、真 `Urms`、基频、正频率频谱和各分量幅值 |
| 扩展带宽 | 50～250 mVpp，10～500 kHz | 与基本要求相同 |
| 抗干扰 | 上述被测信号叠加 200 mVpp、频率不低于 1 MHz 的单频干扰 | 抑制干扰后完成波形、参数和频谱测量 |

题目主要精度指标：

- 频率分辨率：500 Hz；
- `Upp` 和真 `Urms` 绝对误差：不超过 5 mV；
- 基频绝对误差：不超过 1 kHz；
- 各频率分量幅值绝对误差：不超过 5 mV；
- 显示屏尺寸不小于 6 英寸；
- 单路 5 V 直流稳压供电；
- 输入端使用 BNC，匹配题目规定的 50 Ω 信号源与电缆。

## 系统结构

```text
50 Ω / BNC 输入
       │
       ▼
模拟前端 + AD9238 CH1
       │  12 bit
       ▼
Cyclone IV E FPGA (EP4CE6E22C8)
  ├─ offset-binary 转有符号码
  ├─ CIC3 抽取
  ├─ Q4 精度扩展
  ├─ 三节 SOS 低通抗干扰
  ├─ 1.25 MSPS / 4096 点分析帧
  └─ 5 MSPS / 4096 点波形帧
       │  SPI1，32 bit 命令/响应
       ▼
STM32F407ZG
  ├─ CMSIS-DSP FFT 与谱峰插值
  ├─ 基波/谐波识别
  ├─ 幅值、相位和 50 Ω 口径标定
  ├─ Upp、真 Urms 和波形重建
  └─ 时域/频域显示状态机
       │
       ├─ UART4：淘晶驰串口屏
       └─ USART1：调试与连续测量数据
```

分析帧的 FFT 频点间隔约为 `1.25 MHz / 4096 = 305.18 Hz`，并在软件中进行谱峰插值。波形显示使用独立的 5 MSPS 帧，以生成完整的 1 周期或 3 周期波形。

## 功能详解

### 1. 上电、联机确认与连续诊断

`main()` 完成时钟、GPIO、SPI1、USART1 初始化后，依次启动 `GSerial`、`GSignalFlow` 和淘晶驰屏驱动。`GSignalFlow` 在上电时通过 SPI 读取 FPGA 固定 ID `0x000004D2`，并在 USART1 输出启动记录：

```text
G_FLOW,boot,id=0x000004D2,online=1,fs=1250000,n=4096
```

其中 `online=1` 表示 FPGA 应答正确；若为 `0`，应首先检查 FPGA SOF 是否已下载、PA4/PA5/PA6/PA7 连接和两板共地。上电后固件默认进入连续分析帧诊断模式，持续输出测量遥测，不自动改写串口屏测量控件。

连续诊断模式的用途是检查采集链和标定结果。屏幕发起时域或频域测量时，固件会等待当前连续帧结束，再执行屏幕任务，避免两个流程同时抢占 FPGA RAM 与 SPI 总线。

### 2. 时域测量与 1 周期/3 周期波形

按下串口屏 `b0` 后，系统完成以下流程：

1. 先清空 `t0`、`t1`、`t2` 和时域波形控件 `s0`，状态栏进入“测量中”。
2. STM32 发送 FPGA 分析采集命令，读取 4096 点、1.25 MSPS 的滤波后采样帧。
3. STM32 对分析帧执行 FFT、峰值检测、基频/谐波匹配和整机标定，得到基频、`Upp` 与真 `Urms`。
4. 将时域数值写入屏幕：`t0` 显示频率、`t1` 显示峰峰值、`t2` 显示真有效值。
5. STM32 再发送 FPGA 波形采集命令，读取 4096 点、5 MSPS 的波形帧。
6. 软件以基波相位为起点定位完整周期，对原始帧进行四点三次插值，重建固定 256 点的 1 周期或 3 周期数据。
7. 根据 `s0` 的实际控件宽度缩放波形点数，再通过透明传输写入 `s0`；读取宽度失败时使用 512 点后备长度。

时域波形并不是简单截取采样帧前若干点：相位对齐与插值使一个完整周期稳定铺满屏幕，避免触发起点变化导致波形横向跳动。显示过程中波形会按当前屏幕控件的绘制方向镜像，以保持实际屏幕上的时间轴方向正确。

### 3. 1 周期与 3 周期切换

按下 `b1` 后，系统在 1 周期和 3 周期之间切换：

- 若最近一次时域测量已经取得有效的 5 MSPS 波形帧，固件只对缓存帧重新进行相位对齐、插值和绘制，不重新采集，不改变 `t0`、`t1`、`t2` 或频域显示。
- 若正在执行 `b0` 时域测量，切换请求会排队，在本次波形帧完成后应用。
- 若尚无缓存波形帧，则记录选择值，在下一次 `b0` 时域测量中生效。

按钮事件具有 120 ms 防抖。UART4 也接受 ASCII `1` 和 `3` 直接设置周期数，便于无屏或页面调试。

### 4. 频域测量与定性频谱

按下串口屏 `b2` 后，系统只执行分析帧采集，不读取 5 MSPS 波形帧：

1. 清空分量字段 `t3`、`t4`、`t5` 与频谱控件 `s1`。
2. 对 4096 点分析帧施加 Hann 窗，执行 CMSIS-DSP 实数 FFT。
3. 仅在 10～500 kHz 正频率区间搜索谱峰，并对峰位置做插值修正。
4. 选择一个基频，并按整数谐波关系匹配最多三个有效分量；不满足谐波关系的明显峰值作为 `spur` 单独记录，避免把干扰误显示为题目谐波。
5. 通过幅频、相频和谐波联合标定将码值转换为毫伏，更新 `t3`、`t4`、`t5`。
6. 将检测到的实际分量按频率相对位置和幅值相对比例绘制到 `s1`，形成题目要求的定性正频率电压频谱。

`s1` 不直接显示未经处理的 FFT 噪声底，而是绘制最多三个已确认的实际分量。频率间隔仍按 10～500 kHz 固定比例映射，因此谱线的相对位置、数量与相对高度对应被测信号；屏幕控件本身没有必要显示绝对坐标刻度，这与题目“定性显示”要求一致。

### 5. 测量量的计算与标定

测量结果由 `SpectrumAnalyzer` 和 `GMeasurement` 两层完成：

| 结果 | 计算过程 |
|---|---|
| 基频 | FFT 峰值检测后进行频点插值；谐波关系用于抑制弱子谐波或非谐波毛刺导致的误判 |
| 分量频率 | 基频乘谐波次数，并使用实际检测峰对结果细化 |
| 分量幅值 | 先由复数频谱/联合拟合得到 ADC 码值，再查频率-幅度二维标定表转换为输入端 mV |
| `Upp` | 按校正后的谐波幅值与相位重建一个周期，取最大值与最小值之差 |
| 真 `Urms` | 按各个独立频率分量的能量求和计算，不用整流平均值替代 |
| 波形相位 | 使用基频余弦/正弦投影估计相位，再用于确定波形显示起点 |

标定数据位于 `STM32/CalibrationData`，包括幅频、相频、谐波幅度补偿与 50 Ω 显示口径相关数据。没有有效标定表时，固件会拒绝输出伪造的 mV 结果，并在串口输出 `G_MEAS,...,cal=0`。

默认启用 0.5 mV 显示量化。量化只作用于屏幕和诊断输出的最终显示值；关闭量化后，显示层直接输出计算结果。该设置不改变 FPGA 采样格式、标定表或原始 FFT 数据。

### 6. 高于 1 MHz 干扰的抑制

抗干扰路径在 FPGA 中完成，避免高频干扰直接进入 MCU 频谱算法：

1. AD9238 CH1 采样值先从 offset-binary 转为以零为中心的有符号码。
2. `g_cic3_decimator.v` 执行三级 CIC 十倍抽取。
3. CIC 输出左移 4 bit，以 Q4 格式保留 SOS 运算中的小信号精度。
4. `g_sos3_lowpass.v` 执行三节 SOS 低通滤波，针对题目 10～500 kHz 有效带宽保留信号并衰减高频干扰。
5. 分析模式在滤波输出上再按 4:1 保存，得到 1.25 MSPS 分析帧；波形模式直接保存 5 MSPS 滤波输出。

对于接近 500 kHz 的弱幅值测量，固件还具备高频连续帧中值合成逻辑，以降低偶发波动。该逻辑只在满足频率、幅值和分量一致性条件时启用，避免对一般频率信号引入额外等待。

### 7. 屏幕控件与状态

| 控件 | 时域任务 `b0` | 频域任务 `b2` |
|---|---|---|
| `t0` | 基频 `F` | 保持上一次时域值 |
| `t1` | 峰峰值 `Vpp` | 保持上一次时域值 |
| `t2` | 真有效值 `Vrms` | 保持上一次时域值 |
| `t3`、`t4`、`t5` | 保持上一次频域值 | 最多三个谐波分量，格式为 `Hn: 频率 幅值` |
| `s0` | 1 周期或 3 周期时域波形 | 保持不变 |
| `s1` | 保持不变 | 正频率定性频谱 |
| `t6` | 显示测量中、就绪和量化状态 | 显示测量中、就绪和量化状态 |

无有效信号时，当前任务对应的数值会置为 `--`，相应波形或频谱控件清空；不会沿用上一次的旧测量值伪装为新结果。屏幕命令发送采用 `FE` 就绪、`FD` 完成握手，透明波形传输失败会由状态机返回错误状态。

### 8. b3 功能键的实际含义

`b3` 是软件功能键，不是模拟前端的物理量程切换：

- 单击并等待 400 ms 判定窗口结束：在优化算法与保留的兼容算法之间切换，同时清空当前测量缓存并重新开始采集；
- 400 ms 内双击：切换 0.5 mV 显示量化开关；
- 两类操作均受 120 ms 防抖保护。

正常竞赛验收建议保持默认的优化算法和量化开启状态。更改 b3 设置后，应重新测量，不应把切换前的显示数值用于比较。

### 9. USART1 调试与连续数据流

USART1 使用 `921600 8N1`，用于调试、上位机记录和整机验收辅助。常见输出类型：

| 前缀 | 内容 |
|---|---|
| `G_FLOW` | 上电 ID、在线状态、原始码值结果、耗时、超时或无信号状态 |
| `G_MEAS` | 已标定的基频、`Upp`、`Urms` 与各谐波 mV 幅值 |
| `G_COMP` | 单个分量的原始码值、标定系数、相位与相对相位诊断 |
| `G_HMI` | 屏幕事件、排队、周期切换、算法和量化状态 |
| `G_STREAM` | 连续采集启动、停止、忙状态或失败后的重试 |

USART1 输入命令：

| 字符 | 行为 |
|---|---|
| `C` 或 `c` | 启动连续诊断采集；若当前任务忙，则返回 busy 状态 |
| `S` 或 `s` | 停止连续诊断；若正在传输当前帧，则在当前帧结束后停止 |
| `?` | 返回串口格式和命令说明 |

连续诊断流只用于串口观察，不主动覆盖屏幕上的时域或频域结果。屏幕测量任务结束后，固件会恢复连续诊断流。

### 10. 超时、异常与并发处理

固件为 FPGA 采集与测量响应均设置 2000 ms 上限，并以 2 ms 周期查询 FPGA 完成状态。常见处理如下：

| 条件 | 行为 |
|---|---|
| FPGA ID 不匹配或 SPI 失败 | 启动记录显示 `online=0`，后续采集失败时输出对应 `G_FLOW,error` |
| 采集超过 2 秒 | 中止本轮任务，清除忙状态并输出 `timeout` 错误 |
| 无有效信号 | 输出 `G_FLOW,no_signal`，清空本任务对应的屏幕字段 |
| 屏幕测量按钮在连续流期间按下 | 当前连续帧结束后排队执行屏幕任务 |
| 屏幕测量按钮在另一屏幕任务期间按下 | 忽略该新请求，避免覆盖正在写入的显示数据 |
| 波形/频谱透明传输失败 | 当前任务报告错误，不把未完整传输的数据当作有效显示 |

上述状态机由 `GSignalFlow_Process()` 在裸机主循环中驱动；UART4 中断只负责接收字节和写入环形缓冲区，不在中断中执行 FFT、SPI 读帧或屏幕批量发送。

## 串口屏交互

淘晶驰屏由 UART4 独占，按钮弹起事件使用 7 字节帧：

| 按钮 | 数据帧 | 功能 |
|---|---|---|
| b0 | `55 01 00 00 FF FF FF` | 执行时域测量并刷新参数和波形 |
| b1 | `55 02 00 00 FF FF FF` | 在 1 周期和 3 周期波形之间切换 |
| b2 | `55 03 00 00 FF FF FF` | 执行频域测量并刷新分量和频谱 |
| b3 | `55 04 00 00 FF FF FF` | 单击切换算法模式，双击切换 0.5 mV 量化 |

波形和频谱通过淘晶驰 `addt` 透明传输发送。固件会等待屏幕 `FE` 就绪和 `FD` 完成应答，避免依赖固定延时。

## 构建

### STM32 固件

使用 Keil MDK 打开：

```text
STM32/MDK-ARM/stm32_FilterShell_2026GA.uvprojx
```

工程目标器件为 `STM32F407ZGTx`，依赖 `Keil.STM32F4xx_DFP 3.1.0`、CMSIS 和仓库内 HAL/CMSIS-DSP 源码。工程已开启 HEX 生成，构建完成后输出位于：

```text
STM32/MDK-ARM/stm32_FilterShell_2026GA/stm32_FilterShell_2026GA.hex
```

也可在 PowerShell 中使用本机 Keil 路径执行：

```powershell
& '<Keil安装目录>\UV4\UV4.exe' `
  -b '.\STM32\MDK-ARM\stm32_FilterShell_2026GA.uvprojx' `
  -j0
```

使用 ST-Link 按 STM32F407ZG 常规流程烧录生成的 HEX。

### FPGA

使用 Quartus Prime 打开 `FPGA/ADC_RAM.qpf`，选择 Revision `ADC_RAM_G` 后执行完整编译。命令行方式：

```powershell
Set-Location FPGA
& '<Quartus安装目录>\quartus\bin64\quartus_sh.exe' `
  --flow compile ADC_RAM -c ADC_RAM_G
```

编译生成：

```text
FPGA/output_files_g/ADC_RAM_G.sof
```

使用 USB-Blaster 下载 SOF。SOF 断电后失效；若要求脱机上电运行，需要按实际配置芯片型号另行生成并烧录 JIC。

## 上板顺序

1. 检查 5 V 电源、模拟前端、50 Ω 输入条件和 FPGA/STM32 电平连接。
2. 先通过 USB-Blaster 下载 FPGA SOF。
3. 再烧录或复位 STM32，避免启动时读取不到 FPGA。
4. 连接淘晶驰屏至 PA0/PA1，并将屏幕串口设为 `921600 8N1`。
5. 可将 USB-TTL 连接至 PA9/PA10，观察 USART1 调试数据。
6. 启动信息中应读到 FPGA ID `0x000004D2`，且在线状态有效。
7. 分别验证时域测量、1 周期/3 周期切换、频域测量和无信号状态。

## 验收建议

至少覆盖以下输入，且逐项确认完成时间不超过 2 秒：

1. 10 kHz、100 kHz、200 kHz 和 500 kHz 单频信号；
2. `10.5 + 31.5 + 42 kHz` 基波/三次/四次谐波组合；
3. `100 + 300 + 400 kHz` 三分量组合；
4. 在上述宽带信号上叠加 `1 MHz / 200 mVpp` 单频干扰；
5. 50 mVpp 与 250 mVpp 量程边界；
6. 1 周期和 3 周期波形切换；
7. 无输入或低于有效门限的状态。

验收时需要同时检查基频、各分量幅值、`Upp`、真 `Urms`、正频率频谱、屏幕稳定性和响应时间。

## 标定注意事项

`STM32/CalibrationData` 中的 4 个 `.inc` 文件会由 `GMeasurementCalibration.c` 直接编译进固件，不可删除。当前标定与既有 AD9238、模拟前端、增益、50 Ω 换算和 FPGA Q4 缩放绑定。

更改下列任一条件后，应重新完成整机标定：

- 模拟前端或输入终端方式；
- ADC、参考电压或通道增益；
- FPGA CIC/SOS 系数或数据缩放；
- 采样率、FFT 长度或频谱算法；
- 信号源 High-Z/50 Ω 幅值口径。

## 当前工程边界

- 仓库包含 STM32 与 FPGA 的核心源码和可重建工程配置。
- 淘晶驰屏页面工程、PCB 工程、模拟前端原理图和机械结构不在本仓库内。
- `Build`、`db`、`incremental_db`、`output_files_g` 等目录为构建时自动生成，不属于源码。
- 修改代码后必须重新执行 STM32 与 FPGA 全量构建，并在目标板上完成实机回归；仅通过主机算法测试不能替代整机验收。
